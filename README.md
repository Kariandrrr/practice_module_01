# КнигоТест — автоматическое создание тестов по загруженной книге (MVP, v1.0)

Сайт по ТЗ: автор загружает TXT-книгу → текст проверяется и режется на фрагменты → генерируется черновик теста
из 5 вопросов (4 варианта, 1 верный) → автор проверяет/правит/утверждает → публикация → читатель проходит тест и
получает балл, объяснения и ссылки на фрагменты. «Автор» и «Читатель» — режимы интерфейса (переключатель в шапке), аккаунтов нет.

> Стек реализации: **Next.js (App Router) + PostgreSQL + Drizzle ORM** (вместо Python/SQLite из ТЗ — по требованиям среды).
> Функциональные требования QUIZ-01…QUIZ-04 и проверки КП-01…КП-04 выполнены без изменений.

## Запуск

```bash
npm install
# DATABASE_URL в .env, по умолчанию:
# DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db
```

### Что сделать с БД (создание таблиц)

1. Должна существовать пустая база PostgreSQL (по умолчанию `app_db`, пользователь/пароль `postgres`):
   ```bash
   psql postgresql://postgres:postgres@127.0.0.1:5432/postgres -c "CREATE DATABASE app_db"
   ```
2. Создайте таблицы одной командой (миграции не нужны):
   ```bash
   npx drizzle-kit push --config drizzle.config.json
   ```
   Либо выполните готовый SQL: `psql "$DATABASE_URL" -f docs/schema.sql`.
3. Запуск:
   ```bash
   npm run build && npm run start     # или: npm run dev
   ```
   Сайт: http://localhost:3000. Данные хранятся в PostgreSQL и сохраняются после перезапуска сервера.

### Необязательно: генерация через LLM
Без настройки используется «заглушка» — эвристический генератор (вопросы с пропущенным словом/числом по тексту книги).
Для генерации моделью задайте переменные (любой OpenAI-совместимый API):
```
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://api.openai.com/v1   # по умолчанию
OPENAI_MODEL=gpt-4o-mini                    # по умолчанию
```
Ответ модели валидируется (5 вопросов, 4 разных варианта, один ключ, цитата реально есть в книге). При ошибке тест остаётся
черновиком, показывается сообщение, можно повторить. Опубликованный тест проходится без модели.

## Схема базы данных (`src/db/schema.ts`, SQL — `docs/schema.sql`)

```
books ──< chunks                    книга → фрагменты (порядок position, диапазон start_char..end_char в books.content)
books ──1 quizzes ──< questions ──< options     тест → вопросы → варианты (is_correct — ключ)
questions >── chunks                вопрос хранит chunk_id (источник) и source_quote
quizzes ──< attempts ──< attempt_answers        попытка → выбранные варианты и балл
```

| Таблица | Назначение |
|---|---|
| `books` | title, filename, content (нормализованный текст), content_hash (повторная загрузка заменяет книгу), status |
| `chunks` | book_id, position, start_char, end_char, text |
| `quizzes` | book_id (уникален — один тест на книгу), status `draft`/`published`, generator, last_error |
| `questions` | quiz_id, chunk_id, position, text, explanation, source_quote, approved (утверждён автором) |
| `options` | question_id, position, text, is_correct |
| `attempts` | quiz_id, score, total |
| `attempt_answers` | attempt_id, question_id, option_id, is_correct |

## Краткая инструкция пользователя

**Автор** (вкладка «Автор»): загрузите `.txt` (UTF-8, ≤ 500 КБ) или нажмите «Загрузить демо-книгу» → на странице книги
нажмите «Сгенерировать тест» → проверьте каждый вопрос (источник открывается по ссылке), исправьте текст/варианты/ключ →
«Утвердить вопрос» (или «Утвердить все») → «Опубликовать». Публиковать можно только когда утверждены все 5 вопросов.
На странице книги есть поиск по словам внутри этой книги и список фрагментов.

**Читатель** (вкладка «Читатель»): выберите тест → ответьте на 5 вопросов → «Отправить ответы» → страница результата с баллом,
правильными ответами, объяснениями и ссылкой на источник. До отправки ключи и объяснения не передаются в браузер.

## Контрольные проверки (приёмка)

| № | Проверка | Результат |
|---|---|---|
| КП-01 | Загрузка пустого TXT, PDF, файла >500 КБ, не-UTF-8 | Понятная ошибка, запись в `books` не создаётся ✔ |
| КП-02 | Поиск «Юпитер спутники» в демо-книге → фрагмент про Юпитер в топ-5; запрос «Наполеон Бородино» → «ничего не найдено» (поиск строго внутри выбранной книги) ✔ |
| КП-03 | У каждого вопроса есть ссылка на фрагмент с подсвеченным исходным предложением; пока не утверждены все вопросы, публикация отклоняется (кнопка неактивна, API возвращает 422) ✔ |
| КП-04 | 3 верных + 2 неверных ответа → «3 из 5»; результат считается на сервере по БД и не зависит от модели ✔ |

Дополнительно: слишком короткая книга → «Недостаточно материала», тест остаётся черновиком с сохранённой ошибкой.
